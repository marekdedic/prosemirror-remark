# Introduction

prosemirror-remark provides support for using the [remark](https://github.com/remarkjs/remark) Markdown parser with the [ProseMirror](https://prosemirror.net/) editor. It builds on the [prosemirror-unified](https://marekdedic.github.io/prosemirror-unified/) package and offers a configurable and extensible way of adding Markdown support to ProseMirror.
